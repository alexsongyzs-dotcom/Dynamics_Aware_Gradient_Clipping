# Collaboration Handoff

本目录是两位开发者之间的轻量级文件中转站，用于交换说明、接口约定、配置片段、实验清单和待合并的小型补丁。它不替代正式分支，也不表示其中内容已经通过验证或应自动合并到 `main`。

## 使用约定

- 每次交接应注明来源分支、提交哈希、文件用途和接收方需要执行的操作。
- 完整功能代码继续在各自的开发分支维护；确认稳定后再通过独立 Pull Request 合并。
- 不在本目录提交数据集、模型权重、检查点、大型日志或训练产物。
- 文件名建议采用 `YYYY-MM-DD_主题_来源分支.md`，避免覆盖对方的记录。
- 合并前应检查差异、配置兼容性和实验状态；未经确认的内容默认仅供参考。
