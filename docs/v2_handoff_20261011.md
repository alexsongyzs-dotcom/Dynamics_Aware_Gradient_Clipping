# 可转发给 lyx：V2 版本核查与原方案复现

请从 develop/yzs 新建独立 checkout，先看 docs/v2_reproduction_guide.md。

版本核查：你完成的确认实验已启用仓库 V2（exposure_target=0.1、init_c=0.5、gamma=0.05），不是 V1。ENGINE_VERSION=lyx1-v1 是训练引擎版本号；policy=dagc 是共用类名。运行 `python -m scripts.verify_v2_identity` 可检查训练源代码摘要、完整参数和320步控制器状态一致性。因此目前不能将负面结果归因于用了 V1。若另有未进入仓库的 V2 文件，请提供文件/提交号，先逐行对比。

之前 V2 在小样本条件下有收益，保留这些结果。请先按原协议独立复现，而不是立即重跑405次或重新调参：FashionMNIST SmallCNN，5000训练/2000测试，15 epochs、恒定LR0.8、batch256、momentum0.9、weight_decay1e-4，seeds300–307。显式配置是 configs/v2/original_fashion_cnn.json。

安装后运行：

```bash
python -m scripts.verify_v2_identity
python -m scripts.run_v2_reproduction --output results/v2_original_recheck_lr0p8 --seeds 300 301 302 303 304 305 306 307 --dry-run
python -m scripts.run_v2_reproduction --output results/v2_original_recheck_lr0p8 --seeds 300 301 302 303 304 305 306 307
```

交付：manifest、全部seed JSON（含轨迹）、运行日志、软件/GPU环境、失败计数及逐种子对照。输出新目录，不覆盖旧结果；更改配置必须另开目录。V2-only入口不包含基线调优，不能单独拿它宣称新优势。
